# Kokoro Reader

[English](README.md) · **繁體中文**

ETINSTW 使用的本機文字轉語音、轉錄、翻譯與影片配音工具。所有處理都在您自己的 Windows
筆電上完成：不需要網路，也不會上傳任何檔案。

| 您手上有 | Kokoro Reader 可以產生 |
|---|---|
| 文字檔（.txt / .md） | 朗讀的語音，播放時逐字標示，可存成 WAV 或 MP3 |
| 影片（英文或中文） | 影片內容的字幕、可校對的譯文，以及換上另一種語言新配音的影片 |
| 字幕檔（.srt）＋對應影片 | 同上，但直接使用您的字幕，不需要轉錄 |

---

## 1. 安裝

1. 執行 **KokoroReader-Setup-1.1.1.exe**。不需要系統管理員權限，只會安裝到您自己的 Windows 帳戶。
2. 若出現 **「Windows 已保護您的電腦」**，請按 **其他資訊 → 仍要執行**。安裝程式沒有公司憑證簽章；
   請只對來自 ETINSTW 的安裝程式這樣做。
3. 選擇安裝程式語言（English 或繁體中文），可勾選 **建立桌面捷徑**，再按 **安裝**。安裝約需幾分鐘。

**系統需求：** Windows 10 或 11（64 位元）、約 5 GB 可用磁碟空間、建議 16 GB 記憶體
（只處理文字和短片時 8 GB 也可以）。

## 2. 啟動與結束

- 從「開始」功能表開啟 **Kokoro Reader**，程式會在瀏覽器中以 `127.0.0.1`（您自己的電腦）開啟。
- 完整的 **使用入門手冊**（附圖 PDF，英文與繁體中文）在開始功能表：
  *Kokoro Reader – 使用入門* 與 *Kokoro Reader – Getting Started*。
- 右上角的 **EN / 繁中** 可切換介面語言；**使用說明** 會開啟程式內的逐步說明。
- 使用完畢請按 **結束**。若只關閉分頁，程式約 5 分鐘後會自動結束（工作進行中不會結束）。

## 3. 朗讀文字檔

1. **開啟檔案** → 選擇 `.txt` 或 `.md` 檔。
2. 選擇 **語言**、**聲音**，也可以調整語氣、語速和停頓。滑鼠停在虛線標籤上可看到說明。
3. 按 **產生**。每次啟動後第一次產生會多花 30–40 秒載入聲音。
4. 按 ▶ 播放，點選任何字可跳到該處。**儲存音訊** 可存成 WAV 或 MP3。

## 4. 翻譯並配音影片：第 1 到第 5 步

按 **開啟影片** 後，步驟列會引導您：**1 轉錄 → 2 翻譯 → 3 校對 → 4 配音 → 5 匯出**。
完成的步驟會變成綠色 ✓；上鎖的步驟 🔒 會在前一步完成後開放。

| 步驟 | 您要做的事 | 小提醒 |
|---|---|---|
| **1 轉錄** | *影片語言* 保持「自動偵測」、*分段長度* 選「約 5 分鐘」、*準確度* 選「最佳」，按 **開始轉錄**。 | 約需影片長度的一半時間（1 小時影片約 30 分鐘），請接上電源。**停止**／**繼續** 會從中斷處接著做，關閉程式後也可以。 |
| **2 翻譯** | *翻譯成* 選「自動」（英文 → 繁體中文、中文 → 英文），或選「關閉」以同一語言重新配音。 | 每段轉錄完成就會立刻翻譯，其餘段落進行時您可以先往下做。 |
| **3 校對** | 在 **校對** 表格逐段檢查譯文。點選一行即可修改，確認後勾選 ✓，或按 **標記本段已校對**。 | 請先處理標有 ⚠ 的行，詳見下方「校對技巧」。 |
| **4 配音** | 選擇聲音（預設：中文 `zm_009`、英文 `af_bella`），按 **產生配音**，再到 **播放與標示** 觀看成果。 | *原始音訊* 預設為 **取代**：移除影片原本的聲音，只保留新配音，不會同時聽到兩個聲音。 |
| **5 匯出** | 勾選需要的檔案，按 **儲存已勾選**。 | 換上新配音的 MP4、只有配音的 WAV、依新配音對時的字幕、原文字幕、雙語字幕。檔名以影片名稱命名，存到「下載」資料夾。 |

### 校對技巧

- **修改：** 點選一行；**Enter** 儲存、**Esc** 取消。**重新翻譯** 會請翻譯器再翻一次；**復原修改**
  會還原機器翻譯。
- **▶** 會在影片中播放這一行，方便確認實際說了什麼。
- **⚠ 只是提示，不是錯誤：**
  - **⤓ 合併**：句子延續到下一行，點選即可把兩行合併。
  - **太長**：可能超出時間，請精簡用字。
  - **不確定**：轉錄時對部分字詞不確定，請聆聽並修正原文。
- 用 **⚠ 標記** 和 **未校對** 篩選尚未處理的行；段落按鈕可在影片各段之間切換。

### 詞彙表：教一次就記住

- 在表格中選取翻錯的字詞，按 **右鍵 → 加入詞彙表**，輸入正確譯法後，按 **加入並修正這一行**
  或 **加入並重新翻譯全部**。
- 中文留空表示保留英文原詞（例如 *FLIR Thermal Studio*）。詞彙表中的詞在表格裡有綠色底線。
- **詞彙表** 按鈕會列出所有詞彙、來源和使用次數。**匯出 .txt**／**匯入 .txt** 可與同事共用。

### 已有字幕檔的影片

**開啟檔案** → 選 `.srt`（略過第 1 步），再 **開啟影片** → 選對應的影片，接著完成第 2–5 步。

## 5. 檔案存放位置

| 內容 | 位置 |
|---|---|
| 進行中的工作、詞彙表、記錄檔 | `%LOCALAPPDATA%\KokoroReader` |
| 您儲存的檔案 | 瀏覽器的「下載」資料夾 |
| 程式本身 | `%LOCALAPPDATA%\Programs\Kokoro Reader` |

解除安裝（Windows 設定 → 應用程式）會移除程式和工作資料夾。若要保留詞彙表，請先匯出。

## 6. 常見問題

| 狀況 | 處理方式 |
|---|---|
| 按「開始轉錄」或「產生」後好像沒有反應 | 第一次載入最多約 1 分鐘，請看進度文字。 |
| 頁面顯示程式已停止 | 從「開始」功能表重新開啟 Kokoro Reader。開始畫面的 **繼續上次的工作** 會帶回上一部影片。 |
| 部分行的配音延遲 | 在第 3 步精簡這些譯文，或在第 4 步提高「最高加速」。 |
| 產品名稱翻錯 | 加入詞彙表一次，之後所有影片都會沿用。 |
| 某些中文字的發音不自然 | 這是中文聲音模型的已知限制；可以換個說法，品牌名稱可直接寫英文。 |

## 維護說明

**從原始碼執行：** `Kokoro Reader.bat`（開啟 http://127.0.0.1:7860）。命令列工具：
`Video to SRT.bat`（把影片拖曳到檔案上）、`transcribe.py`、`translate_srt.py`。

| 路徑 | 內容 |
|---|---|
| `app/server.py` | 本機網頁伺服器（Flask，只綁定 127.0.0.1）與 API |
| `app/engine.py` | Kokoro 聲音、SRT 對時、WAV／MP3／MP4 輸出 |
| `app/pipeline.py` | 分段轉錄、翻譯、詞彙表、校對提示、中斷後繼續 |
| `app/static/` | 網頁：`index.html`、`style.css`、`app.js`、`i18n.js`（英／繁中）、`guide.js`（使用說明）、`icons.js` |
| `app/glossary-starter.txt` | 新安裝時預設的詞彙 |
| `models/opus-mt-*` | 翻譯模型（CTranslate2 int8），由 `get_mt_models.py` 產生 |
| `tools/ffmpeg/` | FFmpeg 9.0 LGPL |
| `build/` | 安裝程式建置（見下方） |

**建置安裝程式：**

1. `.venv\Scripts\python.exe build\build_dist.py` 會組出 `build\dist\KokoroReader`（內嵌 Python、
   套件、程式、ffmpeg、Kokoro 聲音、Whisper 與 Opus-MT 模型、授權檔）。
2. `build\tools\innosetup\ISCC.exe build\KokoroReader.iss` 會產生
   `build\output\KokoroReader-Setup-<版本>.exe`。請先把 `.iss` 中的 `AppVersion` 調高。

安裝後的程式以 `python\pythonw.exe app\launcher.pyw` 執行，設定 `HF_HUB_OFFLINE=1`，工作檔案存在
`%LOCALAPPDATA%\KokoroReader`，按 **結束** 或最後一個分頁關閉約 5 分鐘後會停止。
