Kokoro Reader on a Mac

Install guide · version 1.1.1 · 繁體中文版：《Kokoro Reader - Mac 安裝說明》

The Mac version works exactly like the Windows version described in Kokoro Reader - Getting Started.pdf. This page covers what is different: installing, starting and where files are kept.

You need: a Mac with Apple silicon (M1 or later; check Apple menu → About This Mac → Chip), macOS 14 Sonoma or later, about 9 GB free disk space while installing (6 GB afterwards). 16 GB memory recommended for long videos.

Install (once)

  1. Double-click KokoroReader-Setup-1.1.1-macOS.zip (about 3 GB). A folder Kokoro Reader 1.1.1 appears next to it.
  2. Drag Kokoro Reader.app from that folder into Applications. Please don't skip this: the app refuses to start from the Downloads folder.
  3. Open Applications and double-click Kokoro Reader. Because it is not from the App Store, macOS says it could not check the app. Click Done (macOS 14: OK).
  4. Open System Settings → Privacy & Security. Scroll down to the message about Kokoro Reader and click Open Anyway. Confirm with your password or Touch ID, then click Open Anyway once more.
  5. A notification says Starting…, and Kokoro Reader opens in your default browser. The first start takes up to two minutes. Later starts are much quicker.
You only allow the app once. From then on, double-click it in Applications or find it with Spotlight (Cmd + Space, type Kokoro).
Still blocked, or more warnings about “python3.12” or a “.dylib” file? Open Terminal (Applications → Utilities), paste this line, press Return, then open Kokoro Reader again:
xattr -dr com.apple.quarantine "/Applications/Kokoro Reader.app"

Uninstall

Drag Kokoro Reader from Applications to the Trash. To also remove your work and the glossary, delete ~/Library/Application Support/KokoroReader and ~/Library/Caches/KokoroReader.

Troubleshooting

What you seeWhat to do
“Please drag Kokoro Reader into the Applications folder first”Do step 2, then open it from Applications.
“needs a Mac with Apple silicon” / “needs macOS 14”This Mac can't run Kokoro Reader. Use a newer Mac or the Windows version.
Nothing opens after two minutesOpen http://127.0.0.1:7860 in the browser. If that fails, send ~/Library/Application Support/KokoroReader/kokoro-reader.log to the person who gave you Kokoro Reader.
